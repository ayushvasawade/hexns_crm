# HEXNS MEDIA --- CRM Service Rate Master

**Purpose:** Update the HexnsMedia CRM service catalogue with each
service's base rate and minimum rate.\
**Currency:** INR (₹).\
**Rule:** If the source rate sheet does not specify a base rate or
minimum rate, use `0`. Do not estimate or invent prices.\
**Important:** Keep service names and billing units as listed. Rates are
numeric values without currency symbols so they can be imported into a
CRM/database.

## CRM Implementation Instructions

1.  Import or update services using the exact service names in this
    file.
2.  Store `Base Rate (INR)` as the standard/base price and
    `Minimum Rate (INR)` as the minimum permitted quote price.
3.  Treat all rates as INR numeric values.
4.  Where both rates are `0`, the source rate sheet did not provide
    prices; keep both fields at `0` until an authorized user sets them.
5.  Do not change existing service names, add new services, or infer
    prices during import.
6.  Preserve the billing unit for display and quotation calculations.
7.  Packages in Section 17 are package records, not individual service
    records; keep them in the CRM's package/category structure if one
    exists.
8.  If a service already exists, update its rate fields rather than
    creating a duplicate.
